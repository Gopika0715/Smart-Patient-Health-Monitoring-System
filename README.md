# 🏥 Smart Patient Health Monitoring System

## 📌 Project Overview
The Smart Patient Health Monitoring System is a Python-based web application developed using Streamlit.

It displays patient health information through an interactive dashboard and helps users review basic vital-sign data.

## 🎯 Objectives
- Monitor basic patient vital signs.
- Display patient records.
- Visualize heart rate data.
- Search patient records using Patient ID.
- Download patient reports as CSV files.

## 🛠️ Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## ✨ Features
1. Patient Overview Dashboard
2. Patient Health Records
3. Heart Rate Distribution Chart
4. Patient ID Search
5. CSV Report Download
6. Basic Vital Sign Status Classification

## 📊 Health Parameters
- Age
- Heart Rate
- Systolic Blood Pressure
- Diastolic Blood Pressure
- SpO₂
- Body Temperature

## 🚀 How to Run the Project

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
